How-To: Create & Manage Leads

Adding a New Prospect

  1. Click Clients in the sidebar
  2. Click the + Add prospect button (top right)
  3. Fill in the form:
    • Company Name — required
    • Website — optional (e.g., https://example.com)
    • Phone — optional
    • Email — optional
    • City — optional but recommended (puts them on the map)
    • Country — optional but recommended
    • Description — optional notes about the prospect
  4. Click Submit to save
Tip: Adding city and country is recommended — it allows the prospect to appear on the Lead Map after geocoding.

Searching Prospects

  1. Go to Clients in the sidebar
  2. Use the search bar at the top to filter by company name
  3. Click any prospect to view full details, contacts, audits, and opportunities

Lead Scores

Each prospect has a lead score from 0 to 100. Higher scores indicate hotter leads.

How-To: Use the Lead Map

Viewing Leads on the Map

  1. Click Lead Map in the sidebar
  2. The map auto-centers on your prospects' average location
  3. Colored markers appear for each prospect with location data
  4. The right sidebar lists all mapped prospects — click any to fly to their location

Searching a Location

  1. Type a city, country, or address in the search bar (top left of map)
  2. Autocomplete suggestions appear as you type
  3. Click a suggestion — the map flies to that location
  4. Use the + and − buttons to zoom in/out

Viewing Prospect Details

  1. Click any marker on the map — a popup shows company name, location, score, and status
  2. A detail card appears at the bottom with industry, website, and status badge
  3. Click the × on the card to close it
Note: New prospects need geocoding to appear on the map. Run this command in the project terminal:
cd stitch_clientos_ai/clientos-ai && pnpm dlx tsx scripts/geocode-prospects.ts

How-To: Use AI Copilot

The AI Copilot is available via the floating button at the bottom right of any dashboard page.

  1. Click Ask AI Copilot at the bottom right
  2. Type your question and press Enter or click Send
  3. The AI fetches real data from your CRM and responds with insights

Working with Opportunities

  1. Go to Sales in the sidebar
  2. View all opportunities and their current stages
  3. Click an opportunity to view details and update its stage
  4. Track total pipeline value and win rate on the dashboard

How-To: Outreach & Email

  1. Go to Outreach in the sidebar
  2. View all conversations with prospects
  3. Click a conversation to see the full email thread
  4. Track which prospects have replied and which need follow-up
Tip: Use the AI Copilot to draft personalized outreach emails based on prospect audit data.

How-To: Website Audits (Intelligence)

  1. Go to Intelligence in the sidebar
  2. View completed website audits for your prospects
  3. Each audit shows findings like SEO issues, performance problems, design flaws
  4. Use these insights to craft targeted outreach messages
Pro Tip: Prospects with poor website scores are more likely to need your services. Target them first!

How-To: Proposals & Contracts

Creating a Proposal

  1. Go to Proposals in the sidebar
  2. Click New Proposal
  3. Select a template or start from scratch
  4. Add sections, pricing, and terms
  5. Save and send to the prospect

Managing Contracts

  1. Go to Contracts in the sidebar
  2. Create a contract from a proposal or template
  3. Add parties, terms, and signature fields
  4. Send for e-signature
  5. Track status: Draft → Sent → Signed

How-To: Project Management

  1. Go to Work in the sidebar
  2. Create a project for a signed client
  3. Assign team members and set milestones
  4. Create and assign tasks with deadlines
  5. Track progress and communicate with the client
